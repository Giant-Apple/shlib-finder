它做什么

查书这件事，本来不该这么费劲

不用在豆瓣、上图网站和地图之间来回切；书单、馆藏、远近放在同一屏。

三种来源，一个书架

豆列、「想读」和手动加的书放在一起；豆列和想读里重复的，只算豆列。书单很长时先显示前面一部分，随时可以接着看；每组能收起，重开页面还是原样。

查到「哪一本能借」

按 ISBN 查每家馆的每一册：在架还是借出、能不能外借、在哪个阅览室、索书号。多个版本先选再查；结果能只看「可借」或「营业中」。

按距离排，也在图上看

479 家馆按远近排，10 公里内给出骑车时间。编号和地图上的点对应，点哪边都能定位，滚轮能缩放。点一下打电话，或打开高德导航。

手机上也能查，只是不能改

手机连着同一个 Wi-Fi，用浏览器打开就行，不用装 App；改设置要回电脑。

书架

书架先说清楚，再去查馆藏

每本书一行：书名、作者 / 出版社 / 年份、ISBN。封面直接标状态：「都已借出」「仅馆内」「无此版本」。

  • 没有 ISBN，先在上图网站按书名找同一版本
  • 只有一个版本就直接查，有多个先让你选，没有就直说
  • 从上图补的书名、作者只填空缺，不改你原来写的
手机

不用装 App，扫一下就能查

在设置里打开「从其他设备访问」，会得到一个同一 Wi-Fi 下能用的网址和二维码。手机浏览器打开就是同一个界面。

  • 只在你家的网络里用，不经过外部服务器
  • 手机上只能查，改不了设置
  • 默认只有这台电脑能打开，共享也只限同一 Wi-Fi
本地优先

查书这件事，不必交出什么

程序装在你自己的电脑上：没有云端账号，也没有人统计你查了什么。

不登录、不统计

只看豆瓣、上图公开的页面；不统计，也不自动更新。查书会连豆瓣、上图和高德；只有你点「检查更新」，才连 GitHub，偶尔走它的加速线路。

只存在你电脑上

书单、查过的结果、地址和高德 Key 都存在你自己电脑上的 config.json 和 data 文件夹里；手输的地址只在查距离时发给高德。

手机上也只能看

手机端只开放查询和地图，拿不到你的地址和 Key；不共享时，只有这台电脑能打开。

「想读」需在豆瓣设为公开，私密列表读不到。

快速开始

三分钟，从下载到第一本书

Windows 下载免安装版；macOS / Linux 用源码运行。

Windows · 推荐

免安装，解压就能用

  1. 打开 下载页，选 shlib-finder-v*.zip。
  2. 解压，双击 start-server.bat。
  3. 浏览器会自动打开查询页面。

关掉弹出的窗口，程序就停了；下次双击 restart-server.bat。

macOS / Linux · 源码

一行命令跑起来

git clone https://github.com/Giant-Apple/shlib-finder.git
cd shlib-finder
./start-server.sh   # Windows 用 start-server.bat

需要 Python 3.9 或更新，不用装别的。出问题看 data/server.log；改完设置点「重启服务」。

第一次打开：设位置（默认人民广场，地址只能填上海）→ 填豆列 / 想读链接（可选，需公开）→ 填高德 Key（可选）→ 要用手机看时再打开共享。也可以直接改 config.json。

常见问题

你可能想先知道的几件事

这个程序和上图、豆瓣是什么关系？

没有关系。非官方项目，与上海图书馆、豆瓣无隶属或合作；馆藏数据来自公开页面。

需要注册或登录吗？

不需要。不填豆瓣链接，也能手动加书、按书名或 ISBN 查馆藏。

「想读」是私密的，为什么读不到？

只看公开的页面，不用你的账号登录。想读要在豆瓣设成公开；设成私密会直接告诉你，不会显示成空列表。

查到的是最新的吗？

是当场从上图取的；12 小时内会沿用上一次的结果，并标出上次是几点查的。想看最新的，点「重新查询」。

一定要申请高德 Key 吗？

不填也能查馆藏，只是没有地址和远近；填了才有地图、骑车时间，也能按远近排。

高德有两种 Key，别拿错：算远近要用 Web 服务，显示地图要用 Web 端（JS API），选错就不会有结果。

2021 年 12 月以后申请的地图 Key，还要配一个「安全密钥」，否则地图出不来。腾讯的 Key 只能把地址变成位置，给不了骑车时间。

地址要在上海吗？距离为什么显示「未知」？

手输的地址只认上海，别的城市会直接拒绝。479 家馆里有 429 家能算出距离，其余显示「距离未知」；没设位置时，按能借的册数排。

开馆时间以各馆公告为准；节假日只提醒，去之前最好打个电话。

macOS / Linux 和手机能用吗？

macOS / Linux 要按源码方式运行；免安装版只有 Windows。

手机连同一个 Wi-Fi，打开给出的网址或扫码，不用装 App。
